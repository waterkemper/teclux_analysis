# Apresentação — Conversão Delphi → Laravel

Abra index.html diretamente no navegador. Não há dependências, build ou servidor necessários.

## Uso na reunião

- Use as setas esquerda e direita, PageUp, PageDown, Home e End.
- O botão Tema alterna claro e escuro.
- Os pontos no canto inferior esquerdo permitem saltar entre os 12 slides.
- O contador e a navegação foram desenhados para apresentação ao vivo, não leitura autônoma.

## Roteiro

1. Ponto de partida e convivência Delphi/Laravel.
2. Mapa de estado dos dez domínios.
3. Mudanças sentidas por quem opera.
4. Quatro provas: transição sem corte, Interlojas, Entregas e Busca Assistida.
5. Caixa e NF-e/NFC-e como especificações para evolução.
6. Help, mobile, marketplaces e Device Gateway com ressalvas.
7. Três perguntas de alinhamento.

## Limites

O artefato não apresenta cronograma, SLA, preço ou substituição imediata do Delphi. “Disponível” significa capacidade confirmada no código/inventário; não significa que todo usuário já foi treinado ou que cada operação está validada em produção.
