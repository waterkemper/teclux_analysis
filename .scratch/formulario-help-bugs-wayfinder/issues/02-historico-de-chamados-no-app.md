## Question

O fluxo atual do Help só envia e-mail para suporte@tecsoft.com.br e devolve um `reference_code` na tela; não existe nenhuma tela dentro do ERP para o usuário ver os chamados que já abriu ou acompanhar status. Isso precisa entrar no escopo da primeira versão, ou fica de fora?

## Answer

**Fora de escopo do v1.** O canal permanece só e-mail + `reference_code` exibido no momento do envio; o usuário guarda o código por conta própria. Uma tela "Meus chamados" com histórico/status é reconhecida como lacuna, mas não é necessária para uma primeira versão prática — pode voltar como esforço futuro se fizer falta na operação real.
