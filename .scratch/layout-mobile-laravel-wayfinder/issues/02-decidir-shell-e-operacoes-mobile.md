# Decidir shell e operações mobile

Type: grilling
Status: open
Blocked by: 01

## Question

Como header, menu, breadcrumb e barras de operação devem se comportar em telas estreitas?

Comparar drawer atual, navegação inferior, header compacto, barra sticky superior/inferior, rail lateral e ações em menu. Definir operação primária, ações secundárias, overflow de comandos, atalhos, foco, overlays, scroll, safe areas, orientação, teclado virtual e interação com modais. Não assumir que o rail desktop possa simplesmente ser reduzido para mobile.
