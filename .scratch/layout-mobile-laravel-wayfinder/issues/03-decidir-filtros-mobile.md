# Decidir padrão de filtros mobile

Type: grilling
Status: open
Blocked by: 01

## Question

Como filtros simples, filtros avançados e ConsultaRuleFilterPanel devem funcionar sem ocupar a tela inteira nem perder contexto?

Comparar toolbar empilhada, painel recolhível, drawer/sheet de filtros e tela dedicada de filtros. Definir botão Filtros com contador, chips de filtros ativos, aplicar/cancelar/resetar, filtros instantâneos versus confirmação, abas, regras E/OU, lookup, preservação de rascunho, retorno do foco e anúncio para leitor de tela. A solução deve impedir que cada consulta invente uma interação diferente.
