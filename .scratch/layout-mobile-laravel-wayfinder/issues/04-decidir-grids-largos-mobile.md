# Decidir experiência de grids largos mobile

Type: prototype
Status: open
Blocked by: 01

## Question

Qual padrão preserva leitura e operação quando uma grade tem muitas colunas?

Prototipar e comparar, usando DataGrid e dados reais representativos: scroll horizontal contido com colunas prioritárias/pinadas; modo lista/cartões com detalhe; seleção de colunas; expansão de linha para campos secundários; e navegação para detalhe completo. Definir como manter ordenação, seleção, edição, resize/reorder, indicadores, paginação, ações de linha, teclado, toque, labels completos e acesso aos dados ocultos. Não aceitar esconder colunas sem informar o usuário e sem alternativa de consulta.
