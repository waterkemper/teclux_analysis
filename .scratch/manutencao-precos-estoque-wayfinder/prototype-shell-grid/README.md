# PROTÓTIPO DESCARTÁVEL — shell e grid da Manutenção de Preços

Questão: qual organização permite filtrar, consultar, editar e revisar todos os registros sem paginação?

Três variações estão disponíveis em uma única página pelo parâmetro `?variant=A`, `B` ou `C`.

Para abrir no Windows:

```powershell
Start-Process .\.scratch\manutencao-precos-estoque-wayfinder\prototype-shell-grid\index.html
```

O protótipo não acessa banco, não grava dados e não representa código de produção.
